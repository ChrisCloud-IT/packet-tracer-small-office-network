\# **Small Office Business Network.** 





\## **Project Overview** 





Designed and configured a simulated small-business LAN using Cisco Packet Tracer. 





\## **Business Scenario** 



ZentrixLabs Solutions Ltd required network connectivity for Finance and Operations workstations together with a shared office printer. 





\## **Technologies** 





\- Cisco Packet Tracer 

\- Cisco IOS 

\- IPv4 

\- Ethernet 

\- ARP 

\- ICMP 

\- Static addressing.





\## **Network** 



192.168.10.0/24 



**Default gateway:** 192.168.10.1 



\## **Infrastructure** 





\- 1 router 

\- 2 switches 

\- 6 workstations 

\- 1 network printer. 





\## **Skills Demonstrated** 





\- Network topology design 

\- IPv4 addressing 

\- subnetting fundamentals 

\- Cisco IOS 

\- router configuration 

\- static host configuration 

\- connectivity testing 

\- ARP analysis 

\- ICMP testing 

\- structured troubleshooting 

\- technical documentation.





\## **Verification Tests included**: 



ping 

ipconfig 

arp -a 

show ip interface brief 

show running-config 





\## **Troubleshooting Exercise** 



OPS-PC02 was intentionally configured with an address belonging to an incorrect subnet. The fault was identified through IP configuration inspection, corrected and verified using ICMP tests. 





\## **Outcome** All workstations successfully communicated with the router, printer and other LAN hosts after remediation.
